## CIVIC360 – Smart Civic Issue Reporting System

CIVIC360 is a web-based platform designed to simplify civic issue reporting, tracking, and management through a centralized digital system.

## Live Demo
[Visit CIVIC360](https://civic360-c4ia7qewrwfubeaj8jxrhz.streamlit.app/)

## Project Purpose
To provide a centralized platform where citizens can report civic issues, share location-based evidence, and track complaint status efficiently.

## Project Impact
Promotes transparency, simplifies civic issue reporting, and supports better monitoring and prioritization of public infrastructure issues.

## Key Features
- Civic issue reporting
- Image evidence upload
- GPS-based location capture
- Issue status tracking
- Administrative dashboard
- Analytics and spatial heatmap

## Usage Workflow
1. Open the CIVIC360 web application.
2. Submit a civic issue with its description, location, and image evidence.
3. View submitted complaints in the issue tracker.
4. Monitor and update issue statuses through the management dashboard.
5. Explore issue trends through analytics and spatial heatmaps.
